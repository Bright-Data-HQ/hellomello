# Polln — competitor analysis

Smaller content-led competitor on a three-property architecture (www +
patient portal + shop). ~4.8K visits / mo across 2,045 ranking keywords;
~70% of traffic is brand. Real library content, named practitioner pages,
and a thin location surface.

```
data/
  raw/                       SEMrush CSVs (Positions, PagesV3, Backlinks)
  screenshots/               site reference screenshots from polln.com
  notes.json                 hand-written qualitative notes
  data.json                  generated by code/analyze.py
presentation/
  presentation.html          live deck (loads ./data.js)
  presentation-offline.html  single-file build (fonts + data inlined)
  data.js                    window.DATA = { … } (generated)
  assets/logo.png
code/
  analyze.py                 CSVs → data.json + presentation/data.js
  audit.py                   pre-build data check
  build_offline.py           inline fonts + data into a single HTML
```

## Rebuild

```bash
python3 code/analyze.py            # CSV → data.json + presentation/data.js
python3 code/build_offline.py      # → presentation/presentation-offline.html
```

Open `presentation/presentation.html` in a browser.

## Data sources

SEMrush exports for `polln.com` (AU database, April 2026):
- Organic Positions
- Organic Pages V3
- Topic Research (kept as reference; not consumed by the analyser)
- Backlinks (per-link export; aggregated to per-page in `raw/`)
