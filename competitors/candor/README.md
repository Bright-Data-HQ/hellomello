# Candor Medical — competitor analysis

A near-pure brand fortress. ~12.7K visits / mo across 472 ranking keywords;
96% of organic traffic is the word "candor". Two properties (www marketing
site + patient app), thin /treatments and /education hubs, no locations,
no practitioners — the site is a brand landing surface, not an organic
engine.

```
data/
  raw/                       SEMrush CSVs (Positions, PagesV3, Backlinks)
  screenshots/               site reference screenshots from candormedical.com
  notes.json                 hand-written qualitative notes
  data.json                  generated by code/analyze.py
presentation/
  presentation.html          live deck (loads ./data.js)
  presentation-offline.html  single-file build (fonts + data inlined)
  data.js                    window.DATA = { … } (generated)
  assets/logo.png
code/
  analyze.py                 CSVs → data.json + presentation/data.js
  audit.py                   pre-build data check
  build_offline.py           inline fonts + data into a single HTML
```

## Rebuild

```bash
python3 code/analyze.py            # CSV → data.json + presentation/data.js
python3 code/build_offline.py      # → presentation/presentation-offline.html
```

Open `presentation/presentation.html` in a browser.

## Data sources

SEMrush exports for `candormedical.com` (AU database, April 2026):
- Organic Positions
- Organic Pages V3
- Backlinks (per-page)
